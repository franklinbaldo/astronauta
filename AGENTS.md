# Astronauta Guidelines

## Repository Structure
- `src/`: Astro pages, components, layouts, and styles.
- `python/`: Python CLI wrapper and integration with `okf-parser` (DuckDB / JSON export).
- `public/`: Static assets and icons.

## Commands
- `bun run dev`: Start Astro dev server
- `bun run build`: Build production static site
- `uv run pytest`: Run Python CLI / integration tests
